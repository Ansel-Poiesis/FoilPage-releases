# 声笺 1.2.0 · 测试版

本版与 [1.1.0 正式版](https://github.com/Ansel-Poiesis/shengjian-releases/releases/tag/v1.1.0-formal) 共享功能与修复，仅版本标记和更新通道不同，供主动参与后续验证的用户使用。版号较大不表示包含额外功能。

- 采用独立测试更新通道；正式版的默认更新通知不会选择本版。
- 包含下载恢复、重复转写反馈、正文操作、未登录 FAQ 与 DNS 兼容性修正。
- 云端年付入口仍为不可购买的占位；实际可购买项目、价格与账户权益以应用内确认为准。

参与测试请主动安装 `ShengJian-Setup-1.2.0.exe`。可选 GPU 包为 `ShengJian-GPU-Pack-1.2.0.zip`；CPU 用户无需下载。升级前建议备份，升级后刷新已打开的视频页。测试反馈请附版本、操作步骤与结果。

安装包未做代码签名，请从本仓库下载并核对 `SHA256SUMS.txt`。安装与浏览器首次配对见 [安装指引](https://github.com/Ansel-Poiesis/shengjian-releases#readme)。
