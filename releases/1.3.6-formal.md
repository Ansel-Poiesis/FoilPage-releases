# FoilPage 1.3.6 正式版

发布日期：2026-11-01

基于 1.3.5 测试通道完成正式版收束。桌面端、浏览器扩展、安装器与 Windows 产品信息统一使用 **FoilPage** 名称。已有安装目录、Windows 应用标识、内部协议与存储键保持兼容。

## 下载

- 安装器：[FoilPage-Setup-1.3.6.exe](https://github.com/Ansel-Poiesis/FoilPage-releases/releases/download/v1.3.6-formal/FoilPage-Setup-1.3.6.exe)
- 可选 GPU 加速包：[FoilPage-GPU-Pack-1.3.6.zip](https://github.com/Ansel-Poiesis/FoilPage-releases/releases/download/v1.3.6-formal/FoilPage-GPU-Pack-1.3.6.zip)
- 校验和：[SHA256SUMS.txt](https://github.com/Ansel-Poiesis/FoilPage-releases/releases/download/v1.3.6-formal/SHA256SUMS.txt)
- 来源与制品清单：[RELEASE-MANIFEST-1.3.6.json](https://github.com/Ansel-Poiesis/FoilPage-releases/releases/download/v1.3.6-formal/RELEASE-MANIFEST-1.3.6.json)

CPU 用户无需下载 GPU 包。安装器和 GPU 包应使用同版本配套文件；发布资产以发行页提供的 SHA-256 清单核对。
