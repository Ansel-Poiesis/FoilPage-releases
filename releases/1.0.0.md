# 声笺 1.0.0 · 正式版

这一版完善了从登录、准备到下载、转写与文稿编辑的完整流程。

- **账户与权益**：邮箱验证码分两步完成，退出后清理登录状态；永久解锁与云端余额分别显示，已解锁用户不再收到泛化的试用提示。
- **准备与设置**：首次配置按登录、环境与目录、本地模型分页；完成后进入任务。统一输入框、下拉菜单、按钮和选中状态，未下载完成的模型不可误选。
- **视频与任务**：导入页支持拖放。可添加本地扫描目录与子目录读取，后台扫描期间仍能使用现有视频；支持播放、打开文件位置与移除登记。任务在后台队列中保留进度，登录恢复后继续。
- **资料与清理**：升级、登录和退出保留本机文稿与历史。失败记录默认保留；可设置保留天数，定期清理仅处理无正文、无文件的空失败记录。
- **桌面体验**：新拟态控件与背景主题统一；窗口操作融入页内，品牌和标题区域可拖动，滚动条去掉上下箭头。引导拆为环境、浏览器和使用三个部分，空白推进，关闭可跳过本轮引导。
- **Agent 与更新**：提供完整／只读 MCP 和随包 CLI，管理内容、模型、提示词与队列；Agent 保存记录与更新通知按需展开。浏览器扩展加载固定安装目录后随桌面升级、空闲重载。

首次启用免费试用 **15 天**，到期 **¥9.90 一次性永久解锁本地软件**。云端充值独立提供标准 **¥19.80／500 积分／30 天**、专业 **¥49.80／2000 积分／30 天**；本地／标准／专业转写并发为 **1／2／4**。正式版不提供新的年付购买。
