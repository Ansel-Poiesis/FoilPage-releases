# 声笺 1.1.0 · 正式版

这一版汇总近期小版本的改进，完善从浏览器下载、转写到文稿编辑的日常流程。

- **下载与恢复**：重复转写即时提示；浏览器下载回退的结果持续可见。桌面未运行时可由扩展拉起；升级后恢复连接与导入，超过一天但仍有效的下载文件也能继续导入。页内通知异常不会阻断下载回退。
- **文稿编辑**：完善正文选择、复制与菜单操作，减少重复操作造成的打断。
- **帮助与说明**：独立 FAQ 在未登录时也可阅读；补全备份包含范围、跨设备媒体迁移与字幕视觉校对的数据说明。
- **连接与升级**：修正 DNS 回退与系统代理、服务端口等解析行为的兼容性；统一桌面、Worker、浏览器扩展与安装器版本标记。

安装 `ShengJian-Setup-1.1.0.exe`，可覆盖升级并保留本机资料；升级前建议先备份。NVIDIA GPU 用户可选配同版本 `ShengJian-GPU-Pack-1.1.0.zip`，CPU 用户无需下载。安装与首次配对见 [安装指引](https://github.com/Ansel-Poiesis/shengjian-releases#readme)。

桌面升级会更新固定安装目录中的扩展文件，扩展空闲时重载，已打开的视频页需刷新。若从历史 **1.1.0 测试版**改装本正式版，因为数字版本相同，请在浏览器扩展管理页手动重载一次。旧测试发行保留，本正式发行标签为 **`v1.1.0-formal`**。

安装包未做代码签名。Windows SmartScreen 提示时可选择「更多信息 → 仍要运行」；请仅从本仓库下载，并使用随附 `SHA256SUMS.txt` 核对文件。
